# 忘记 Key 后同页保存修复

日期：2026-10-14

## 修改

修复设置页点击“忘记 Key”后，继续输入新 Key 或修改设置时，被误判为其他面板修改的问题。

前端忘记请求携带打开设置页时的版本；后台先检查版本，再将 Key 删除标记与递增的设置版本一起提交。成功时返回本次实际提交的设置签名，前端用该签名继续保存，不需要关闭并重新打开设置。

前端不会用后续普通刷新得到的任意版本覆盖编辑基准。如果另一面板在忘记前修改设置，忘记请求被拒绝；如果另一面板在忘记成功后修改，后续保存仍被拒绝，避免覆盖其他面板的新 Key 或供应商设置。

受版本保护的忘记路径读取旧会话 Key 时不提前迁移写入，合并后的 Key、空值删除标记和设置版本只有一次本地提交。保存失败不返回成功版本，不清空用户输入，也不推进编辑基准。保留不带版本参数的原有内部 Key 调用返回值兼容性。

生产修改位置：`extension/background.js`、`extension/dashboard.js`。保留当前供应商之外的 Key，保持空白设置输入保留有效 Key 的语义。
