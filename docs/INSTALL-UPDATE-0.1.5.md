# 拾签 / Pickmark 0.1.5 更新说明

修复本轮审核发现的菜单定位及预览异步状态问题。保留原型交叠预览、高清截图、单一操作菜单、中文切换、行距自动列表、人工分类、书签和历史补分类。

## 更新

1. 完成正在保存的操作，关闭旧插件页面及侧边栏。
2. 在 `chrome://extensions` 开启开发者模式，找到原插件。
3. 原加载目录为 `/Users/abelguan/Desktop/Tab/extension` 时，代码已更新，直接点击原插件的“重新加载”。
4. 其他目录：把 ZIP 内文件覆盖到原插件目录，保持目录位置不变，`manifest.json` 直接位于该目录内，再点击原插件“重新加载”。
5. 确认版本 **0.1.5**，原插件 ID 未变，再打开体验。

不要卸载原插件或换目录安装第二份，否则可能清除数据或改变存储身份。本版不重置数据、人工分类、书签元数据、历史、规则、Key 或图片缓存。

点击工具栏图标打开或切回完整页面；网页上右键点击插件图标，可通过 Chrome 原生菜单打开侧边栏。浏览器导航页保持原样。

侧边“···”菜单提供打开网页、查看大图、调整分类、复制链接；缩屏和滚动会关闭菜单，可在新位置重新打开。悬停交叠效果与 JPEG 85%、最多 1200×750 的截图保持。缓存最多 100 张、约 1.5 MB、7 天；自动截图仍须主动开启和授权，常见邮箱、无痕与排除域名不采集。

首次安装：解压到固定目录，在 `chrome://extensions` 开启开发者模式并“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的目录。

包内不含真实书签、邮箱、个人 Key 或浏览器配置。本轮仅用模拟数据与独立测试浏览器验证。
