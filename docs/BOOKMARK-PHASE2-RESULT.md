# 书签第二阶段完成说明

本轮补齐书签的分类管理与本地规则功能。没有增加书签 AI、新标签页导航，也未访问真实书签、邮箱或个人 Chrome 配置。

## 分类管理

- 点击名称直接编辑，Enter 保存、Esc 或失焦取消。
- 「···」菜单提供重命名、更换图标、合并、删除。
- 图标支持自动匹配与手动选择，并在智能分类侧栏使用；原文件夹仍与智能分类区分。
- 左侧手柄支持拖拽、方向键排序；顺序独立于标签分类。
- 合并迁移书签的智能分类和关联规则；删除归入待整理，不删除书签、不移动浏览器目录。
- 重命名保留人工状态；合并/删除后的归属受人工调整保护，后续规则整理不会覆盖。

## 分类规则

- 新增、编辑、删除；编辑后保留原优先级。
- 拖拽与键盘排序，按第一个匹配执行。
- 已保存规则与编辑表单分区，规则备份折叠显示。
- 导出仅包含关键词与分类，标明书签来源，不包含网址、目录、历史或 Key。
- 导入提供新增/重复数量和规则预览，确认后追加新关键词；保留已有顺序，跳过重复关键词。不导入 AI 偏好，不修改标签规则。
- 使用与标签规则兼容的备份格式；书签界面确认导入的目标始终是书签空间。

## 数据与性能保护

书签写入增加版本检查，过期操作会报错，不覆盖其他面板更新。规则名称、长度、重复项、排序目标和分类操作均经过校验。旧数据没有版本号时从 0 开始，不需要清空或重新授权。

浏览器书签树只读；分类、图标、顺序、规则和版本保存在插件独立本地数据中。没有调用书签移动、重命名或删除 API。

列表/网格每页 100 条、预览缓存 20 项上限保持。搜索和规则整理覆盖全部匹配结果，不限当前页。

- 书签管理完整交互、规则编辑/排序/导入导出、标签空间隔离和多尺寸布局通过。
- 分页、第二页人工修改、末尾条目搜索与整理、缓存上限通过。
- 原有双面板、分类排序、列表/网格、设置回归通过。
- 历史补分类确认/取消、规则处理、无 Key、已关闭页面、已有分类和人工调整保护通过。
