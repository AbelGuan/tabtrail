# 拾签 / Pickmark 0.1.4 安装与更新

恢复预览与列表交叠的原型效果，保留高清截图；修复中文设置显示；右侧只保留操作菜单；点击任一行距按钮自动切到列表。

## 已安装插件

1. 完成保存，关闭旧插件页面与侧边栏。
2. 打开 `chrome://extensions`，开启开发者模式，找到原插件。
3. 如果原加载目录是 `/Users/abelguan/Desktop/Tab/extension`，代码已更新，直接点击原插件“重新加载”即可。
4. 其他加载目录：把 ZIP 内的文件覆盖到**原插件目录**，`manifest.json` 直接放在原目录中，再点击原插件“重新加载”。保持目录位置不变。
5. 确认版本 **0.1.4**、原 ID 未改变，再打开插件。

不要卸载旧插件、改变加载目录或安装第二份来更新，以免改变存储身份或清除数据。本版保留人工分类、书签分类、历史补分类、设置、Key 和缓存。

## 使用

- 点击工具栏图标打开或切回完整页面；网页上右键点击插件图标，通过 Chrome 菜单“打开侧边栏”。本版不替换浏览器导航页。
- 悬停显示交叠预览。“···”菜单提供**打开网页、查看大图、调整分类、复制链接**。调整分类不是重命名网页。
- 点击“紧凑列表”或“舒适列表”时，即使当前为网格，也直接切为对应列表。
- 中文/English 切换会更新预览设置及说明，保留表单中的未保存输入。
- 自动截图仍需要在设置中主动开启并授权。仅截图实际浏览的允许网页；邮箱、无痕、排除网站跳过，截图不发送给 AI。
- 图片最多 1200×750，缓存最多 100 张、约 1.5 MB、7 天；旧低清图片需重新浏览后更新。清理预览缓存不删除人工分类、书签分类或历史。

首次安装时，将 ZIP 解压到固定目录，在 `chrome://extensions` 开启开发者模式并“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的目录。

包内不包含真实书签、邮箱、个人 Key、浏览记录或 Chrome 配置。
