# P2 修复复审（2026-10-13）

后续补测：真实 MV3 慢响应、后台强制终止及恢复验证已完成，详见 [生命周期回归报告](LIFECYCLE-REGRESSION-20261013.md)。下文“验证边界”记录的是本轮初次审核时的覆盖范围。

结论：本轮未发现需要报告的新缺陷。在已检查的代码和回归覆盖范围内，没有发现此次修复破坏历史补分类或原有功能的证据。这不是对所有运行环境均无问题的保证。

## 审核范围与判断

- 复查 `classification-request.js`、`background.js` 的请求派发与串行队列，以及普通整理、历史补分类两条工作流。
- 请求发出前重新核对记录、排除规则、暂停状态、分类上下文和凭据；后台再次校验，并在串行队列内启动请求，避免重新出现原 P2 的发送前竞态。
- 后台返回包含待完成请求的对象，网络等待在串行队列外进行；因此慢请求期间仍可处理暂停、清空等消息。结果提交继续受现有上下文和记录状态校验保护。
- 历史补分类保留候选筛选和提交校验：已有分类、人工调整（含人工保留待整理）、其他日期及范围外记录不会被覆盖；分类结果仍写入历史快照，供继续浏览恢复使用。
- 新增记录签名忽略采集时间、激活次数等记账字段，避免普通浏览活动造成无意义失效；标题、分组、人工标记和快照发生变化时终止旧请求符合保留用户修改的要求。

## 验证边界

浏览器测试使用模拟凭据与供应商响应，没有发送真实浏览数据。历史浏览器回归使用实际后台模块，但未以真实 MV3 service worker 生命周期运行；普通工作区浏览器测试的后台通信采用模拟处理器，后台逻辑另由单元测试覆盖。因此本轮尚未实测真实供应商超过 30 秒的慢响应、扩展 worker 被系统终止、浏览器关闭或重启期间的请求。保活定时器和结束清理已有模拟测试，不能据此宣称上述真实生命周期场景全部验证通过。
