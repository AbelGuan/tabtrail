# 拾签 / Pickmark 0.1.6

2026-10-26 · 清理后本地体验包。相较于保留的 0.1.5 安装包，本版汇总了之后完成的正式界面修改。

- 「分类与规则」可直接切换标签页与书签，两边数据独立；人工调整和历史补分类继续保留。
- 顶部外观菜单支持浅色、深色和跟随系统，与设置同步；列表在窄屏优先保留网站图标和名称。
- 五个页面标题使用液态图标，保留现有 Logo、重叠反差和悬停条纹动效。
- 预览在组内固定、跨组下移，支持窄屏和往回浏览；空格、Delete、Backspace 始终操作当前键盘焦点。
- 「关于与帮助」包含可跳过、返回和重看的真实界面引导；第三步说明 AI 配置。开源、反馈和赞赏二维码继续等待真实内容配置。
- 设置说明、底部状态栏和无截图占位已精简。权限、隐私、AI 费用和删除后果提示保留。
- 未引用的旧样式和图标已移出运行包，历史原型和导出资料归档。

本次没有新增后台数据迁移或重置逻辑，也未新增权限。按包内「安装与更新说明」覆盖原目录更新，保持插件 ID；原有记录保留策略继续生效。
