# Tabkeep · 列表悬停交互确认

已查看用户提供的 [录屏](</Users/abelguan/Movies/DogSC/导出/区域 · 2026-10-13 07-06-52-30fps.mp4>)。本次确认的是 List 模式中“行内反色动画与右下预览联动”的整体效果。

## 你要的交互

1. **平时**：书签或标签以整齐的文字列表呈现。
2. **鼠标移入某一行**：左侧色块先展开，再出现逐渐变细的竖条，接着右侧区域展开反色；文字位置固定。
3. **预览显现**：对应网页的缩略图随后在列表右下方浮现，与列表叠层展示，列表位置固定。
4. **换到另一行**：旧行的效果退出，新行展开；同一个预览位置切换为新条目对应的网页画面。
5. **鼠标离开**：行内效果按节奏收走，预览隐藏，回到文字索引。

录屏里预览内容是视频；Tabkeep 对应展示网页缩略图即可。重点是反色、条纹与预览之间的联动，以及浏览多个条目时的连贯感。

这一交互已用于 03「错位秩序」的书签、标签、历史清单和每日回顾路径。原型使用模拟书签、标签和缩略图。实际插件、历史补分类实现以及真实书签和邮箱不在本轮变更范围内。

已完成[完整双面板原型](../archive/2026-10-26/prototypes/bookmark-directions/03-offset.html)，包括 8 个主要页面，以及搜索、分类调整、整理确认和预览弹窗。缩略图在右下固定位置浮现；快速划过条目会取消过时的预览；支持键盘聚焦，窄屏通过眼睛按钮打开预览，减少动态效果跟随系统。具体演示与验证说明见[原型说明](../archive/2026-10-26/prototypes/bookmark-directions/README.md)。
