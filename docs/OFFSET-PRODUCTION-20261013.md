# 拾签 / Pickmark · OFFSET 正式插件接入

参考：用户提供的 `Pickmark-OFFSET-03-Mono-2026-10-13.zip`。本轮已修改 `extension/`，不是再创建独立原型。原型文件保持独立。

## 使用

在 Chrome 的扩展管理页对**现有插件点击「重新加载」**，然后重新打开插件面板。继续使用当前 `extension/` 路径，以保留现有扩展 ID 与本地数据。无需卸载、清空记录或重新导入分类。

界面采用原型的黑白灰、点阵标题与数字、刻度、紧凑列表、底部状态栏、悬停分段反色、双面板导航、窄屏侧栏以及深色模式。品牌显示为「拾签 / Pickmark」。运行时使用真实数据，数量、日期、标题等自然与模拟原型不同。

## 接入与保留的功能

- 标签工作区、每日回顾、继续浏览使用原有记录与工作流；列表支持人工分类、搜索和打开页面。
- 原有 AI 供应商、Key 管理、连接测试、分类偏好、规则导入导出、规则排序、工作区迁移/删除、暂停记录和排除网站仍使用原实现。新增页面仅替换展示层和入口。
- 历史补分类继续通过 `history-workflow.js` 与后台提交，保留已有分类与人工调整。新增历史人工编辑会同步更新对应 `snapshotGroup`，避免界面显示与恢复清单不一致。
- 仅保留列表与网格，支持紧凑/舒适行距；旧卡片、尺寸重置和经典/圆角切换已移除。已保存的卡片视图自动迁移为列表，其他偏好和分类数据保留。分类排序移入「工作区管理」，支持拖拽和方向键调整并持久保存。
- 每日回顾保留真实 24 小时时段、十五分钟选择、轨迹图、详细记录和分页，不用原型的模拟时长替代真实统计。
- 状态栏与 ↑↓ / J/K、Enter、空格、E、/、⌘/Ctrl K、Esc 键盘操作已接入。标签工作区的 Delete / Backspace 关闭当前选中的真实标签。

## 书签与隐私

书签采用 `optional_permissions: ["bookmarks"]`，首次进入显示授权入口；未授权前不读取书签。分类保存到独立的本地元数据键，不调用移动、重命名或删除原书签目录的 API。原文件夹与智能分类是两种展示维度；书签规则独立于标签规则，目前在本地执行，不发送书签给 AI。

新增 `activeTab` 用于**用户明确点击保存**当前可见网页的缩略图。仅在目标网页确实是当前可见、非无痕且不在排除列表时尝试捕获；请从该网页的插件侧边栏操作。浏览器没有授予临时权限时会拒绝捕获，不绕过权限。不会自动切换、打开、抓取书签或后台网页，不调用外部缩略图服务。

悬停读取本地缓存，缺失时显示明确的占位信息；不使用虚构图片冒充真实网页。缓存最多 10 张、约 1.5 MB，7 天过期，在访问/更新缓存时清理；清空浏览记录也清空预览，排除网站后移除相关缓存。图片不发送给 AI。

开发与验证均使用临时隔离浏览器、模拟记录、人工构造的测试书签和本机模拟 AI 服务。没有读取用户真实 Chrome 配置、书签或邮箱。

## 文件

`offset-theme.css` 与 `offset-icons.js` 复用批准原型的视觉定义；`offset-live.css` 适配已有功能控件；`offset-ui.js` 连接现有数据与表单。`bookmarks.js`、`thumbnails.js` 分别隔离书签元数据与手动预览缓存。历史批处理和请求中断策略继续沿用原工作流。
