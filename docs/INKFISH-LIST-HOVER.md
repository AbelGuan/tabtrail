# Inkfish · 仅 List 模式的悬停效果

这次只检查 [Inkfish Work](https://inkfishnyc.com/work) 的 **List**，连续观察移入、横向移动、换行和移出。上一轮回答混入了 Grid 的鼠标跟随效果，未准确聚焦用户指定的交互。

## 实际看见的过程

1. 移入条目，左侧品牌名区域的色块先从左向右展开，覆盖处文字反色。
2. 中间一组逐渐变细的竖条错开时间展开，形成类似条码的过渡带。
3. 右侧项目资料区域随后展开大片反色背景，文字保持原位。整个过程有先后节奏。
4. 移出时，色块和竖条分段擦走；迅速换行会同时看到旧行退出与新行进入。
5. 在同一行内左右移动，条纹位置仍固定在列之间。

## 另一个关键层：右下方视频预览

悬停会同时显示一个视频元素。实际 DOM 中它从隐藏切换到显示；在 1440 × 1000 的测试窗口里，位于右下方约 x=900、y=641，大小 540 × 305，层级在列表之后。

**这部分只确认了触发和位置，没有看见播放画面。** 视频请求被当前浏览器以 `ERR_BLOCKED_BY_ORB` 拦截，播放器未就绪。因此不能声称已经完整看到用户浏览器里的悬停效果，也不能将此归因于网站本身在所有浏览器都有问题。
