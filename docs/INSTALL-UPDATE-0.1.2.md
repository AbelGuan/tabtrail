# 拾签 / Pickmark 0.1.2 安装、更新与预览使用说明

日期：2026-10-14。本版修复列表/网格点击及网页预览，保留现有数据、人工分类、书签和历史补分类。

## 已安装插件：不要卸载，按原目录更新

1. 关闭插件的旧完整面板和侧边栏，完成正在保存的操作。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启“开发者模式”，找到原插件并记下 ID。
3. **如果原加载目录是 `/Users/abelguan/Desktop/Tab/extension`，代码已经更新，不用解压或重复安装，直接点击该插件的“重新加载”圆形箭头。**
4. 如果原来加载自其他目录，解压 `Pickmark-0.1.2.zip`，将其中的文件覆盖到原插件目录，再点击原插件的“重新加载”。原目录的位置和名称保持不变；`manifest.json` 应直接位于原目录内，不要把新文件夹嵌套进去。
5. 确认版本为 **0.1.2**、ID 未改变，再从工具栏重新打开插件。核对熟悉的人工分类和历史日期。

不要点击“移除”或换到新目录安装第二份来更新。Chrome 移除扩展会清除其本地存储；本版本沿用原存储键，没有重置分类或书签元数据。[Chrome 存储说明](https://developer.chrome.com/docs/extensions/reference/api/storage#storage_areas)、[重新加载说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#reload_the_extension)

本版本没有增加默认授予的网页截图权限。原用户更新后仍需主动开启自动预览并通过 Chrome 授权。

## 怎样让网页生成缩略图

1. 打开插件的**设置 → 界面与交互 → 自动保存网页预览**。
2. 点击“开启”，同意 Chrome 的网站访问授权。你也可以从预览弹窗点击“开启自动预览”。Chrome 截图 API 对自动截图需要 `<all_urls>` 授权；授予后，本功能只对允许且当前可见的网页截图。[Chrome 截图权限说明](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)
3. 正常切换到一个网页，等待加载完成并停留约 1–2 秒，然后回到插件。
4. 列表悬停或点击眼睛按钮可看到已保存预览；网格直接显示缓存图片。

**不会一次性打开所有标签或书签。** 从未实际浏览过、没有缓存、缓存已过期或被淘汰的网址仍会显示占位；再次浏览允许的网站可生成预览。已加载但始终放在后台的页面不会被抓取。

自动预览只保存本机 JPEG，不发送给 AI，也不调用第三方截图服务。仅截图普通、已加载、浏览器聚焦的当前可见网页；无痕页面、暂停记录、排除域名及常见邮箱站点跳过。其他敏感网站可在设置中添加排除域名。

截图缩小到最多 **640×400**，缓存最多 **100 张且约 1.5 MB**，保留 **7 天**；不会因书签数量增加而无限累积图片。原有 30/14/7 天历史记录政策保持，图片期限与历史记录期限独立。

## 点击操作

- 列表：左侧图标/网站名、递减过渡条、标题及普通内容区域都打开网页。
- 网格：图片与标题区域直接打开网页。
- 眼睛按钮：只预览，不打开网页；弹窗内另有“打开网页”。
- “···”按钮：调整分类，不触发打开网页。
- 键盘：方向键逐条移动，Enter 打开，Space 预览；左侧多了可点击区域，也不会让方向键在同一行反复停留。

## 手动更新预览

需要刷新某个页面的截图时，先打开它，并在该网页的插件侧边栏预览对应条目，点击“更新当前网页预览”。只有目标网页确实当前可见时才显示此操作。

在完整插件面板中，网页本身处于后台，因此弹窗显示“打开网页”，不再提供一个必然失败的隐藏页面保存操作。自动预览授权后无需逐页手动保存。若只想手动采集，可关闭自动预览，回到网页后点击 Chrome 工具栏插件图标，再从其侧边栏保存；`activeTab` 临时权限由点击工具栏图标授予。[activeTab 说明](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)

清理预览缓存可用设置中的“数据与存储 → 清理预览缓存”；它不清空人工分类、书签分类或历史记录。关闭自动预览停止后续自动截图，已经保存的图片仍可查看或清理。

## 首次安装

已有旧版请按上面的更新步骤操作。

1. 解压 ZIP，将文件夹放到一个固定位置。
2. 打开 `chrome://extensions` 并开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的解压文件夹。
4. 在拼图菜单固定“拾签”，点击工具栏图标打开侧边栏。不要在安装后移动该目录。
5. 按需连接书签、配置 AI，或开启自动预览；这些功能分别授权，不会在首次加载时批量采集网页。
