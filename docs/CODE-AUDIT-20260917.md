# 2026-09-17 已开发功能与代码核查

本次对照对话确认的产品范围，核查 extension 全部 JavaScript、manifest、主要界面、打包与检查脚本。修复以下已确认问题，没有新增停留计时、跳转路径或云端功能。

## 已修复

1. **重新分组范围不一致**：继续浏览预览的是历史记录，执行器却仅接受今日且仍打开的页面。现在重新分组仅在工作区提供，历史视图没有此入口。
2. **手动分组可能被漏掉**：旧 ruleMatched 标记会让主动重新分组跳过手动页面。手动修改清除旧标记，主动重新分组也明确包含人工归属，日常自动整理仍保留人工归属。
3. **AI 结果提交时的竞态**：原先只在页面端检查规则／偏好变化，后台写入前仍有空隙。现在后台提交再次核对分类上下文、记录开关、今日记录及页面是否仍打开；暂停时也不再应用本地规则。
4. **暂停时不清理过期记录**：将保留期限检查独立出来，后台读取时也执行 30 日／5,000 条上限及排除过滤，不依赖采集开关。没有增加后台定时器；浏览器关闭期间不会运行清理程序。
5. **规则数量与备份格式不一致**：原先手动可添加超过 1,000 条，导致导出验证失败。手动新增现在遵守相同上限，达到上限仍允许编辑。
6. **旧实现残留**：清除无作用的 autoOrganize 设置字段及旧 popup 样式、过时提示；更新 UI 回归脚本中仍假设回顾显示工作区卡片的断言。添加界面 ID 唯一性及 JavaScript 元素引用检查，防止删除按钮后遗留空引用。

## 功能边界核对

| 能力 | 当前实际状态 |
| --- | --- |
| 固定插件图标打开侧边栏 | 已配置，使用 Chrome sidePanel API |
| 打开工作区自动分类 | 已实现；工作区可见时调度，免费规则优先，AI 结果缓存，批量上限 200 页／次 |
| 独立一键整理按钮／新标签页工作区菜单／旧 popup | 已移除；Logo 是非交互 span |
| 三个一级导航 | 工作区、每日回顾、继续浏览，位置固定 |
| 每日回顾 | 日期及页面数、网站数、标签激活次数；不展示工作区卡片 |
| 停留时长／完整跳转路径／注意力判断 | 未实现，也没有相应采集权限或后台统计；界面已说明 |
| 继续浏览 | 每日收集页面与最后分组、阅读状态；恢复未打开的 URL，跳过重复。不恢复滚动位置、表单、窗口布局或完整浏览器会话 |
| AI 偏好 | 用户填写并应用；未勾选保存仅在 Chrome 会话，勾选才持久化。没有隐式学习用户偏好的能力 |
| 分类规则导入导出 | 只备份整理方式，可选已保存偏好；不导出 URL、浏览记录或 Key |
| 云同步、账户服务、正文抓取、完整浏览器历史读取 | 没有实现 |
| 普通网页预览 | 使用示例数据，不访问真实 Chrome 标签、不保存 Key、不调用真实 AI |

Chrome 自带扩展设置入口仍由 manifest.options_page 指向设置视图；这与已经移除的产品菜单“新标签页打开工作区”不同。它不是日常整理入口。
