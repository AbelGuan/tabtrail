# 0.1.3 高清预览与完整页面入口

2026-10-14。截图从 640×400、低质量两次压缩改为最多 1200×750、两次 JPEG 质量 85%，维持比例并释放临时 bitmap。预览浮层改为正层级、不透明背景，避免列表文字叠在截图上。

缓存总大小仍约 1.5 MB，最多 100 张、7 天，权限和敏感站点保护不变。当前画廊分页、图片延迟加载、最多 20 条 UI 预览缓存、同页 5 分钟截图间隔及截图限流保持。旧截图自然更新，不主动打开网站或批量重拍。

工具栏 action 打开或聚焦完整 dashboard。独立启动队列避免连续点击重复创建；匹配扩展自己的 dashboard 路径，接受查询参数和视图 hash，排除侧边栏 surface，优先当前窗口并保留原视图。启动不读写设置、分类或历史，独立于 AI/存储队列，不因容量不足阻塞。Chrome 原生右键菜单侧边栏入口及 manifest 声明保留。没有增加导航页替换或额外默认权限。

验证使用 Node 模拟 API、临时 Chrome 配置、本机模拟页面和模拟书签；未访问个人 Chrome 配置、真实书签或邮箱。

## 验证结果

- Node 全套 **153/153** 通过：高清缩放、JPEG 参数、bitmap 释放、较大图片容量淘汰；完整页面并发打开、视图保留、窗口聚焦、异常后重试、错误路径及侧边栏路径排除；以及现有分类、书签、历史补分类、容量、清理、设置/Key 原子提交、崩溃恢复和旧 AI 防回写测试。
- `npm run check`、`git diff --check` 通过。
- 实际 Chrome 临时配置：真实本机网页截图尺寸超过旧 640 像素上限且仍不超过 1200×750；列表悬停浮层位于列表上方；列表/网格打开网页、独立预览、异步图片、手动保存、关闭/清理预览通过。Chrome API 实际并发启动仅创建一个完整页面，再次打开保留 hash 视图。
- 原有 MV3 浏览器回归通过：历史人工快照、书签分类持久化且原目录不变、预览保护、关闭标签和侧边栏 surface。
- 实际 ZIP 同目录 reload 测试通过：ID 不变，人工分类、书签元数据、记录/规则、供应商 Key 和语言逐项一致。该测试用本版代码临时标为 0.1.0 后植入模拟数据再更新，验证更新操作的数据保留，不等同于重新运行历史版本源码。

旧缓存不会凭空变高清，重新访问允许的网页后更新；同页防重复间隔最多 5 分钟，或在可见网页的侧边栏手动更新。更高画质意味着相同字节预算下缓存图片数量可能减少；新图解码时的单张像素内存也会增加。缓存字节/数量/期限、分页、延迟加载和 UI 缓存上限保持，没有把 10,000 条书签全量转换成截图。
