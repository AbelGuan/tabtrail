# 0.1.5 操作菜单、语言和行距闭环审核

日期：2026-10-14。审核对象为 0.1.4 的操作菜单、设置语言更新、行距自动列表及其对预览缓存的影响。所有浏览器验证都使用独立临时配置、本机模拟网页、模拟标签及书签；未读取个人 Chrome 配置、真实书签或邮箱。

## 已复现并修复的问题

1. **P2：菜单在缩屏、滚动后仍留在旧坐标。** 窗口从桌面缩到手机宽度，菜单可能移到屏幕外。现在缩放、滚动改变按钮位置时关闭原菜单，用户可以在新位置重新打开。打开前触发、打开后才送达的滚动事件不会误关闭新菜单；第二页书签的真实浏览器回归也覆盖了这一点。测试曾观察到应关闭的菜单仍有 1 个，修复后通过。
2. **P2：跨面板语言切换中断尚未完成的大图。** UI 重绘使旧图片请求失效，却没有重新读取当前大图；已有图片也没有按最新排除配置重绘。现在独立保存明确打开的预览条目和所属面板，重绘后校验条目仍存在、面板一致，再更新预览及语言。条目已删除或面板改变则关闭预览，缓存变化按该明确条目刷新，避免被其他选中行替换。已复现语言切换后图片加载超时，修复后通过。
3. **P2：旧的预览状态响应覆盖较新的自动预览状态。** 大图的状态响应原来会直接修改全局自动预览开关；慢响应可能把新状态改回旧值。现在大图只更新自身，开关状态通过独立、带请求序号的读取更新；新状态变化时刷新打开的大图，旧图片/状态请求继续按预览令牌拒绝。已复现 true 被旧 false 覆盖，修复后通过。
4. **P2：快速关闭再打开时，旧 close 事件取消新大图。** 浏览器的 close 事件异步派发，旧事件可能清空刚打开的预览状态并使新图片失效。现在事件处理先检查弹窗是否已经重新打开，忽略过期的 close 事件。已复现新大图加载超时，修复后通过。重新绘制时也保留仍存在的弹窗按钮焦点。

## 复审范围与数据边界

- 菜单的四个按钮都是普通按钮，不提交设置表单。打开、分类、大图和复制分别调用原有路径；复制只写剪贴板，不读取剪贴板。
- 分类仍经过原有标签 patch / 书签 patch 路径，人工标记、历史快照和书签版本冲突保护保持；书签原目录不移动。
- 语言更新只重写设置标题、说明及开关文字，不重建配置表单；模型和模拟 Key 的未保存输入保留，分类名称和选项值不因翻译变化。
- 行距按钮只切换当前面板的布局并保留筛选、分页与分类；公共行距偏好沿用原设计，不写分类数据。列表/网格操作与键盘入口保持。
- 新的重绘读取仅查询缓存/状态，不截图、不打开网页、不调用 AI。缓存仍最多 100 张、约 1.5 MB、7 天；UI 图片缓存仍最多 20 条，图库分页和延迟加载保持。
- 清理缓存、记录删除之后，之前延迟返回的图片不能重新填入当前 UI 缓存或重开已关闭的预览。本版不修改后台保存、容量裁剪、历史补分类或旧 AI 结果校验路径。

新增 `scripts/ui-interaction-review.mjs`，8 组浏览器回归全部通过，覆盖菜单缩屏/滚动及延迟事件、跨面板语言与慢图片、排除缓存图片、旧状态返回、快速关闭重开、乱序开关读取、清空缓存后的旧图片、删除条目后的旧图片、以及未保存设置保留。

- Node 全套 **153/153** 通过；语法、权限、CSP、元素引用、中英文元数据和空白检查通过。
- 原有全页面模拟 UI 回归通过：分类排序、人工分类、独立书签规则、语言、明暗主题，以及 320–1440 宽度布局。
- 本机网页/临时 MV3 配置回归通过：高清截图、列表/网格与菜单大图、延迟图片、手动保存、缓存关闭/清理、历史人工快照、书签分类持久化且原文件夹不变、标签关闭及侧边栏。
- 1,000 条模拟书签分页回归通过：第二页人工分类、全范围规则整理/搜索、列表/网格和 UI 缓存上限保持。
- 更新包测试在植入模拟数据前，通过正式设置接口暂停记录并等待启动队列完成，另加断言确认人工状态已正确初始化，避免直接写配置与启动采集竞态。更新检查对保存的数据逐项比较，不忽略时间戳或缩小断言范围。
- 实际压缩包同目录重新加载通过：ID、本地分类/书签/历史/规则/供应商 Key 与语言不变。测试将当前源码临时标为旧版本后植入模拟数据再更新，用于验证更新操作，不等同于运行历史版本源码。

复审未发现上述覆盖范围内尚未解决的人工分类、书签、历史补分类或预览缓存回归。本轮没有修改后台分类、记录裁剪和 AI 提交代码。
