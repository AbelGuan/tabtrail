## 改正的主要表述

1. **“页面记录”不等于“阅读过”。** 后台采集打开的标签，前台片段才用于时间估算；不声称判断实际阅读或心理专注。
2. **记录和 AI 触发不同。** 面板关闭后本地记录仍可继续；自动 AI 需要可见工作区。主动连接测试独立于记录开关。
3. **“关闭标签不会发 AI 请求”过于绝对。** 关闭本身不要求重做缓存分类，但同步时仍可能处理未完成候选。
4. **AI 不单独发完整 URL 字段，不等于输入文本绝无网址。** 标题、工作区名、规则和偏好可能包含敏感内容。
5. **“排除网站”不是撤销内容脚本权限。** 后台清理和过滤页面数据，网页检测脚本仍可能运行；已保存的同名规则文字也不会自动删除。
6. **日期只在当前面板保留选择。** 不承诺刷新后或多个面板共享所选日期；默认日期可跨日更新。
7. **工作区迁移与历史片段不同。** 页面归属和每日快照会迁移，已经采集的片段仍保留当时分组。
8. **同 URL 合并为一条页面记录，而非一个工作区卡片。** 一个主题卡片可以包含多个页面。
9. **支持适配器不等于所有模型可用。** 模型表明确是代码预填值，真实账户与供应商尚未逐家验收。
10. **30 天是上限。** 数量和预算可能提前裁剪；约 4 MB 仅是片段的应用层估算。
11. **规则备份不是整机数据备份。** 不包含浏览清单、Key 或全部显示设置；恢复页面不恢复滚动位置、表单、登录状态和窗口布局。
12. **源码公开、Release 与商店上架分开。** 本地检查通过不等于已上传、已发布或已上架。

删去 README 中未确定的下一步功能清单，避免读者把它理解成已承诺的路线图。历史审查结论保留，并在导航和历史文件中强调日期与适用边界。
