# 拾签 / Pickmark 0.1.1 安装与更新说明

打包日期：2026-10-14。此包为修复后的本地体验版，使用 Chrome“加载已解压的扩展程序”安装。

## 已安装旧版：按原目录更新，保留数据

**沿用原来的 Chrome 用户配置、插件目录和扩展 ID；不要点击“移除”，不要先卸载再安装到新目录。** Chrome 会在移除扩展时清理扩展的本地存储，其中包含插件保存的分类、历史和配置。[Chrome 存储说明](https://developer.chrome.com/docs/extensions/reference/api/storage#storage_areas)

1. 先在原有插件确认当前分类和书签分类可见，记下 `chrome://extensions` 中该插件的 ID。完成正在保存的操作，关闭插件的完整面板和侧边栏。
2. 查看该扩展的详情，确认它当前“加载自”的文件夹。
3. 如果当前目录就是 `/Users/abelguan/Desktop/Tab/extension`：这个目录已更新为 0.1.1，直接进入第 5 步即可。
4. 如果加载自其他目录：解压 `Pickmark-0.1.1.zip`，将其中的插件文件复制覆盖到**原来的插件目录内**。保留原目录的位置和名称，不要把新文件夹嵌套放到旧文件夹里。更新后的原目录应直接包含 `manifest.json`、`background.js`、`dashboard.html` 和 `icons`、`_locales` 等文件/文件夹。说明文档可一起复制，不影响插件。
5. 在 `chrome://extensions` 确认右上角“开发者模式”已开启，找到原插件，点击其卡片上的“重新加载”圆形箭头。[Chrome 重新加载说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#reload_the_extension)
6. 确认版本变为 **0.1.1**，并确认 ID 与更新前相同。重新点击工具栏图标打开侧边栏；完整面板也重新打开。
7. 检查熟悉的人工分类、工作区、分类规则、书签分类和“继续浏览”日期记录。保持原 ID 更新时，本版本继续使用原存储键与数据结构，没有初始化或重置现有分类的操作。

如果同时出现两个插件、ID 不一致或数据像首次安装一样，请先回到原插件及原加载目录核对。不要通过“清空记录”解决更新问题。此包不包含个人数据，加载成一个新扩展不会自动复制另一个 ID 的数据。

当前版本把 Key 持久保存在本机，并按供应商隔离；已有持久化 Key 在原 ID 更新时保留。Chrome 重载会清空会话存储。如果使用非常早期仅临时保存 Key 的版本，更新后可能需要重新填写 Key；规则导出不备份 Key，也不备份完整浏览记录。[Chrome 会话存储说明](https://developer.chrome.com/docs/extensions/reference/api/storage#storage_areas)

## 第一次安装

已有旧版的用户请使用上一节，不要重复首次安装。

1. 解压 ZIP，将解压后的文件夹放到固定位置，例如“文稿/Pickmark”。不要在安装后移动或删除此文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的解压文件夹**，不要选择 ZIP 文件。
5. 在工具栏的拼图菜单中固定“拾签”，点击图标打开侧边栏；可在插件中展开完整面板。

首次默认跟随系统外观，语言根据系统选择；首次安装没有另一扩展 ID 的历史或人工分类。书签读取是可选权限，只在你使用书签功能并同意时授予。AI Key 可稍后填写；书签 AI 会先显示待处理范围，由你确认后发送标题和域名。[Chrome 加载说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load_an_unpacked_extension)

## 这版可以体验什么

- 标签页与书签两个面板，列表和网格展示，分类图标、搜索与预览。
- 工作区/书签分类管理、图标、排序、人工调整、合并和规则。
- 标签 AI 分类、指定日期的历史补分类、需确认范围的书签 AI 分类。
- 同一设置页忘记旧 Key 后可保存新 Key，多面板互相修改时提示重新打开设置，避免覆盖。
- 默认保留最近 30 天记录，可选 7/14 天。自动清理和容量上限可能提前删除旧历史；当前打开标签的人工分类、书签分类与规则保留。更新不取消这一已有清理政策。
- 容量不足时可打开设置和清理入口；失败保存不部分修改数据；旧 AI 结果不会恢复已删除记录。

建议更新后先看看现有分类和近期历史是否正常，再体验改名、图标或同页更换 Key。无需为了验证版本主动清空记录。
