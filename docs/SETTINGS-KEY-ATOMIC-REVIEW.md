# API Key 整体提交：复审报告

结论：**本轮未发现需要修复的新问题。** 在本次检查和测试覆盖范围内，空白保留、多供应商隔离、容量失败、强制退出和多面板保存符合预期；人工分类、书签及历史补分类回归通过，未复现旧 AI 恢复已删除记录。

## 检查结果

- **空白保留**：缺省、空字符串和纯空白不覆盖当前供应商 Key；读取旧会话凭据不提前写入，本地已有值优先，明确忘记的空值不会被旧会话凭据恢复。
- **多供应商隔离**：遍历全部六个供应商，空白切换保持整张 Key 表不变；非空替换仅更新所选供应商，人工分类保持不变。
- **容量与保存失败**：Key 与设置、记录、缓存及书签分类处于同一次容量检查和写入中。模拟浏览器拒绝与内部容量保护均不改变已有本地数据；失败不增加设置版本，原面板可以重试。
- **多面板**：只改 Key 也更新设置版本。同一旧版本并发保存只接受一次；忘记 Key 后的旧面板不能重新覆盖它。
- **旧 AI**：设置提交同时推进历史版本及书签修订号；历史提交校验当前版本与记录存在性，删除记录未被旧结果恢复。
- **表单**：真实界面只发送一次设置保存请求，未再发送独立 Key 保存请求；演示页也不会把消息中的 Key 合并进普通配置。
