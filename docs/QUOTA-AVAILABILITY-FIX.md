# 容量不足时的可用性修复

已修复 P2：存储空间不足时，插件仍可打开，进入设置、查看存储占用和使用清理入口。

## 行为

- 采样、维护或密钥迁移因容量不足失败时，页面重新读取最新已保存的数据，明确提示空间不足，并提供“设置与清理”入口。
- 已打开标签的人工分类即使保存在之前日期，也会在恢复视图中展示；不创建虚假的已保存记录。
- 容量统计和书签读取不再依赖标签历史维护写入。密钥正常迁移行为保留，只有容量不足时使用只读读取。
- 容量不足提示期间暂停界面自动分类调度；腾出空间并重新加载后恢复正常流程。记录开关没有被修改。
- 数据修改仍使用原来的统一写入保护，失败继续报错，不伪装为保存成功。不扩大容量、不删除受保护人工分类、不移动浏览器书签。
- 回退只处理容量错误，其他错误仍正常上报。回退读取最新存储，避免把此前已成功清理的记录从旧快照带回来。
