# 记录保留与清理：完成说明

已应用到现有插件，在「设置与隐私 → 数据与存储」使用。

## 本次交付

- 默认保留 30 天，可选 7 天、14 天；缩短期限前显示删除数量和日期范围并确认。
- 每日自动维护过期记录、停留片段及缩略图缓存；启动或恢复使用时补做。后台重新唤醒不会重置每日维护计时；暂停记录仍会维护。
- 手动提供「清理预览缓存」「清理旧记录」「清空回顾记录」。取消确认不会删除数据。
- 显示页面记录数、停留片段数、本地存储用量与最近维护时间；存储用量不标为内存占用。
- 清理前先保留已知的当前打开标签状态，包括人工分类；当记录预算紧张时优先保留今日人工分类。
- 不关闭标签，不删除书签，不改分类规则。清空回顾不会暂停后续记录。
- 清理会使旧的标签 AI 分类结果失效，避免已删除历史被重新写回。保留期内的历史补分类继续可用。

## 验证

所有测试只使用模拟数据和隔离浏览器资料目录，没有访问真实书签、邮箱或个人 Chrome 资料。

- 109 项单元/集成测试通过，静态检查通过。
- 新增日期边界、7/14/30 天、长期未启动的人工分类保护、暂停记录后的定时清理、保存设置后即时裁剪、拒绝不支持的天数、缓存独立清理、迟到 AI 写入失效和预算保护测试。
- 界面回归覆盖清理确认与取消、保存保留期限、中英文切换、窄屏、当前人工分类保留。
- 历史补分类回归覆盖确认、取消、本地规则、缺少 Key、已关闭页面、不自动打开标签和人工调整保护。
- 原有书签管理、规则编辑/排序/导入导出、合并删除、标签页隔离测试通过。
- 全新临时 Chrome 中的真实 MV3 回归通过：历史人工快照、书签分类持久化且原目录不变、预览保护、侧边栏及标签关闭功能。
- 模拟 100、1000、10000 条历史均完成清理；一万条纯清理计算约十几毫秒。实际时间受设备和存储写入影响，不是整个浏览器的内存承诺。

## 保留的限制

仍有最多 5000 条页面记录、12000 段停留片段和存储容量上限，可能早于所选天数裁剪；当前人工分类优先保留不等于无限容量。已删除的历史无法回顾或补分类。浏览器关闭期间不会运行任务，下次运行时补做。清理插件记录不会释放用户仍然打开的网页自身占用的全部内存。
