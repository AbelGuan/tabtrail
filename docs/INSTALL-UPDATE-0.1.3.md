# 拾签 / Pickmark 0.1.3 安装与更新

本版提高网页预览清晰度，修复列表内容穿过预览浮层的问题。点击工具栏插件图标默认打开完整页面；已经打开时切回原页面，保留所在面板与设置，不重复创建。侧边栏保留，导航页替换尚未启用。

## 已安装：沿用原目录更新，不要卸载

1. 完成正在保存的操作，关闭旧插件页面和侧边栏。
2. 在 `chrome://extensions` 开启开发者模式，找到原插件并记下 ID。
3. 如果原加载目录为 `/Users/abelguan/Desktop/Tab/extension`，代码已经更新，直接点击原插件的“重新加载”圆形箭头即可。
4. 如果原加载自其他目录，将 ZIP 中的文件覆盖到原目录，保持目录位置不变。`manifest.json` 直接放在原目录中，不要套一层新文件夹，再点击原插件的“重新加载”。
5. 确认版本为 **0.1.3**、ID 未改变。点击插件图标，检查人工分类、书签及历史日期。

不要移除旧插件或换目录安装第二份来更新。移除插件会清除 Chrome 保存的扩展本地数据。本版不重置数据、Key、规则、人工分类、书签分类或历史。

## 打开方式

- 点击工具栏插件图标：打开完整页面；已有页面则切回，并聚焦它所在的窗口。已有多个页面时优先切回当前窗口的页面。
- 侧边栏：在网页上右键点击工具栏插件图标，选择 Chrome 的“打开侧边栏”。侧边栏与完整页面共用现有数据。
- 点击 Chrome 的“＋”仍打开原来的新标签页；本版没有替换导航页。

## 高清预览

在 **设置 → 界面与交互 → 自动保存网页预览** 开启并同意 Chrome 截图权限。正常浏览允许的网页，加载完成后停留约 1–2 秒，再回插件查看。旧截图不能靠放大变清楚，需要重新浏览后更新；同一网址有 5 分钟防重复截图间隔。希望立即重拍时，可在网页侧边栏中预览该条目，点击“更新当前网页预览”；也可先清理预览缓存后重新浏览。

截图最多 **1200 × 750**、JPEG 质量 85%，保持原比例、不放大小网页。缓存仍最多 **100 张、约 1.5 MB、7 天**；高清图片更大，实际保留数量可能少于 100。读取缓存不自动打开页面、不触发截图；图库继续延迟加载图片，悬停和弹窗共用缓存。

不会自动打开未浏览的书签或后台网页。无痕、常见邮箱、排除域名不截图；暂停记录时停止自动截图。截图只存本机，不发送给 AI。其他敏感域名可在设置中排除。

完整页面查看大图使用眼睛按钮；网页处于后台时不能手动截图。需手动采集时，先授权截图，允许关闭自动采集但保留已授予权限，再通过网页侧边栏手动保存。

**设置 → 数据与存储 → 清理预览缓存** 只删除截图，不清除人工分类、书签分类或历史。原历史 30/14/7 天保留设置及历史补分类保持。

## 首次安装

解压到固定文件夹，在 `chrome://extensions` 开启开发者模式，点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的文件夹。在拼图菜单固定“拾签”，点击图标打开完整页面。书签读取、AI 与自动截图分别按需使用和授权。

包内不含真实书签、邮箱、个人 Key、浏览记录或 Chrome 配置。测试仅使用临时模拟配置与网页。
