# 0.1.4 界面交互调整

- 恢复 OFFSET 原型中预览与列表文字交叠、反色的效果，保留 1200×750 / JPEG 85% 的高清截图和原缓存限制。上一版为修复遮挡而提升浮层层级，改变了用户希望保留的设计，本版撤回这项层级调整。
- 设置里的“悬停缩略图”“自动保存网页预览”及说明、开关随语言实时刷新；不重建配置表单，不丢失未保存的输入。
- 列表和网格只保留一个“···”操作入口：打开网页、查看大图、调整分类、复制链接。没有独立眼睛按钮，鼠标悬停与 Space 大图预览仍保留。菜单支持键盘打开、Escape 关闭、点击外部关闭；复制只写入剪贴板。
- 分类调整明确是移到已有工作区/分类或新建分类，不修改网页名称；书签分类提供已有分类建议，保留原浏览器文件夹。没有新增移动/删除原书签的操作。
- 点击“紧凑列表”“舒适列表”自动切回当前面板的列表，显示当前行距状态；标签页和书签布局仍分别保存于当前 UI 实例，不互相切换。

本版修改 UI 和版本号，分类写入、人工保护、历史补分类、AI 防旧结果回写、容量裁剪和清理后台路径未改变。使用模拟数据、独立临时浏览器验证，不访问真实书签和邮箱。
