# 拾页双面板交互原型

另有独立视觉探索版：`tabkeep-living-index.html`，主题为 **THE LIVING INDEX / 活页索引**。墨绿导航、纸白画布、荧光黄选中态、衬线大标题、档案编号与固定预览展台；支持索引/画廊切换及纸白/夜绿主题。预览插画由内置 SVG 绘制，完全离线。原来的双面板原型仍保留，两个文件互不覆盖。

视觉探索版的交互检查为 `check-living-index.mjs`，对应截图以 `living-index-` 开头。已检查双面板状态、分类范围、原目录及人工分类保留、历史补分类与恢复演示、回顾下钻、搜索、预览、主题和 1280 / 1024 / 768 / 390 / 320px 布局；无页面异常、无 HTTP 请求。

直接打开 `tabkeep-dual-panel.html`，无需服务器、安装插件或网络连接。

可体验：

- 标签页 / 书签切换，各自保留搜索与分类选择。
- 标签工作区、每日回顾、继续浏览及历史补分类演示。
- 书签原文件夹 / 智能分类；修改分类不改变原目录。
- 悬停缩略图、预览按钮、页面打开演示与人工分类。
- ⌘K / Ctrl+K 搜索，输入后按 Enter 筛选列表。
- 列表 / 卡片切换，经典 / 圆角与系统 / 浅色 / 深色外观。
- 窄屏抽屉导航与底部预览。

使用 14 条模拟标签、16 条模拟书签和 9 条模拟历史记录。所有缩略图为内置 SVG 示意画面，已标明并非真实截图。点击打开只展示说明；分类、恢复和同步是交互演示，不执行浏览器操作。刷新后恢复初始数据。

未修改 `extension/` 中的现有插件。没有 Chrome API 调用、个人数据读取、外部脚本、远程图片或 AI 请求。CSP 禁止网络连接。

本原型不重做原插件全部设置：中英文切换、真实规则管理和供应商配置等仍属于原插件，此处用说明保留边界；历史恢复演示不实际打开页面。它用于确认双面板结构和交互方向，不是可安装的新版本。

`check-dual-panel.mjs` 使用隔离 Chrome 检查双面板、目录保留、搜索、人工分类、范围限制、历史补分类、回顾交互、预览和主题，以及 1024 / 768 / 390 / 320px 宽度。测试同时断言无 HTTP 请求和页面异常。PNG 文件是对应演示截图。
