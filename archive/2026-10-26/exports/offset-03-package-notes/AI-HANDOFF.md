# 给其他 AI 的交接说明

## 项目定位

产品名：拾页 / Tabkeep。当前交接的是 **03 / OFFSET「错位秩序」完整交互原型**，用同一套视觉组织标签页与书签。所有页面在一个 HTML 入口中切换，不是八个独立 HTML 文件。

先阅读 `README.md`，再查看 `03-offset.html`、`offset-app.css`、`offset-app.js` 和 `screenshots/`。能运行浏览器时请亲自体验悬停；截图不能完整表达动画。

## 已确认的设计方向

- 黑、白、橙；大号无衬线标题、细分隔线、紧凑索引列表和非对称版面。
- 用户明确不喜欢墨绿 × 纸白组合，请避免将设计改回该配色。
- 顶部「标签页 / 书签」切换，左侧当前面板导航；两面板保留各自的筛选、搜索与显示方式。
- 八个主要页面：标签工作区、每日回顾、继续浏览、书签原文件夹、书签智能分类、工作区管理、分类规则、设置与隐私。
- 共用搜索、列表 / 画廊、分类调整、预览、主题与响应式布局；不要因改视觉而删除功能入口。

## 必须理解的悬停效果

参考效果来自 Inkfish 的 List 模式及用户提供的录屏，核心是：

1. 左侧来源色块先展开。
2. 中间逐渐变细的 12 道竖条依次展开。
3. 右侧页面区域展开反色，文字位置和行高固定。
4. 对应网页缩略图在列表右下方固定位置浮现，处于列表下层；它不跟随鼠标移动。
5. 切换条目更新缩略图，取消过时的延迟任务；离开隐藏预览，列表不跳动。

当前实现主要使用 CSS 伪元素、`mix-blend-mode: difference`、横向缩放及分段延迟。`offset-app.js` 中 `rowHTML`、`bindHover`、`select`、`positionPreview`、`clearHover` 负责结构与联动。`art` / `specimenArtwork` 生成内置 SVG 示意图。键盘聚焦提供同样的预览，窄屏通过眼睛按钮打开弹窗，减少动态效果跟随系统设置。

不要将它误读为卡片放大、行内展开、预览随鼠标移动，或必须播放视频。本产品希望显示网页缩略图；目前使用模拟画面。

## 功能约束与模拟逻辑

- 书签「原文件夹」和「智能分类」是两种组织维度，调整智能分类不会改变原目录。
- 标签与书签的分类规则分别配置。
- 历史补分类只处理当前范围里没有人工调整的「待整理」记录，保留已有分类和人工选择。
- 历史记录在补分类之后再次被人工调整时，恢复快照也要保持一致。
- 恢复清单演示会复用已有模拟标签；真实插件如何识别 URL、处理窗口等，不由此原型定义。
- 所有变更只在内存保留，刷新重置；没有联网、账号、存储或真实采集能力。

## 包装说明

三个运行文件保留打包时的原始内容。`index.html` 是本压缩包新增的交接索引，承接源码已有的页脚链接；压缩包不包含另外三个视觉方向。`MANIFEST.json` 可验证文件哈希。未附带用户提供的私人录屏、生产插件、浏览器数据、账号信息或其他项目文件。

## 可复制给其他 AI 的开场说明

> 请先阅读这个压缩包的 README.md 和 AI-HANDOFF.md，运行 03-offset.html 并查看截图。以 03 / OFFSET 的黑白橙设计及「左侧色块 → 递减竖条 → 右侧反色 → 固定位置网页缩略图」为基础理解页面。当前只是一份使用模拟数据的设计原型；后续具体改动以我另外给出的要求为准。保留双面板与已有交互，尤其是历史补分类对已有分类和人工调整的保护，不要访问真实书签、邮箱或浏览器个人资料。
