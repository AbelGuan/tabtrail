# Tabkeep / 拾页 · OFFSET 03 设计交接包

这是 03「错位秩序」的完整双面板 HTML 原型，打包日期为 2026-10-13。解压后直接用浏览器打开 **03-offset.html**，或打开 **index.html** 查看文件入口和截图目录。无需安装依赖、启动服务器或登录账号。

## 包内文件

- `03-offset.html`：原型入口。
- `offset-app.css`：黑白橙视觉、响应式布局、分段反色动画。
- `offset-app.js`：模拟数据、页面渲染、悬停缩略图与交互流程。
- `AI-HANDOFF.md`：给其他 AI 的设计与实现说明，含可直接复制的任务描述。
- `screenshots/`：13 张效果截图，覆盖八个主要页面、列表悬停、画廊、深色设置与移动端。
- `check-offset-app.mjs`：可选的隔离浏览器回归脚本，普通查看原型无需运行。
- `MANIFEST.json`：文件清单、大小和 SHA-256，便于确认文件完整。

HTML、CSS、JS 必须放在同一个目录。压缩包只包含 03，不需要 01、02、04 或现有插件。原型页脚沿用了「四版对比」文案；本独立包的该链接会打开交接包索引，而非另外三版原型。

## 页面和使用方法

顶部切换「标签页 / 书签」，左侧选择页面；窄屏点击左上菜单。

| 页面 | 可体验的功能 | 截图 |
| --- | --- | --- |
| 标签工作区 | 分类筛选、列表 / 画廊、整理、人工调整、预览 | `offset-full-tabs.png` |
| 每日回顾 | 网站 / 工作区分布、选择小时、浏览路径 | `offset-full-review.png` |
| 继续浏览 | 日期选择、历史补分类、恢复清单演示 | `offset-full-history.png` |
| 书签原文件夹 | 文件夹筛选、原目录保留、预览 | `offset-full-bookmarks.png` |
| 书签智能分类 | 主题筛选、整理、人工调整 | `offset-full-smart.png` |
| 工作区管理 | 新建、重命名 | `offset-full-manage.png` |
| 分类规则 | 分面板配置网站规则、启停规则 | `offset-full-rules.png` |
| 设置与隐私 | 系统 / 浅色 / 深色、预览开关、重置 | `offset-full-settings.png` |

悬停任何列表项，体验「左侧色块 → 递减竖条 → 右侧反色 → 网页缩略图」。眼睛按钮可固定预览，更多按钮可调整分类。⌘/Ctrl K 打开搜索，Esc 关闭预览 / 弹窗。历史记录的模拟日期是 **2026-10-12**。

补充截图：`offset-full-hover.png` 是悬停完成状态；`offset-full-gallery.png` 是画廊；`offset-full-night.png` 是深色设置；`offset-full-mobile-folders.png`、`offset-full-mobile-review.png` 是手机布局。截图为演示过程中截取，部分分类或主题可能已经手动调整；刷新原型会恢复初始状态。动画先后顺序请实际打开 HTML 体验，静态截图只能展示一个时刻。

## 模拟范围与验证

包含 14 个模拟标签、16 条模拟书签、9 条历史记录。缩略图为本地 SVG 示意网页，数据只存在页面内存中，刷新重置。不读取真实书签、邮箱或浏览器个人资料，不调用 Chrome API、AI 或外部网络，也不写浏览器存储。点击页面标题只演示打开流程。

此包是设计和交互原型，不包含生产插件，也不等于已实现真实书签同步或网页截图采集。现有插件和历史补分类实现未修改。

打包前已有隔离浏览器验证：八个页面、分段动画、固定行尺寸、快速悬停切换、键盘与窄屏预览、分类保护、历史补分类及恢复、搜索 / 画廊 / 规则 / 主题；1440 / 1024 / 818 / 768 / 390 / 320 px 无横向溢出，零页面错误、零外部请求。

如需重跑验证，安装 Node.js、Playwright 与 Chrome 后在解压目录运行 `node check-offset-app.mjs`。脚本通过 `PLAYWRIGHT_MODULE` 可指定已有 Playwright 模块位置；它创建临时隔离浏览器并阻止 HTTP(S) 请求，生成的截图保存在解压目录根部。
